# نظام النجار الذكي 🌿

تطبيق ويب عربي RTL لإدارة طلاب حلقات القرآن الكريم، والحضور، والاشتراكات والمدفوعات، ومتابعة التسميع والتقارير. يحفظ التطبيق سجلات الطلاب الحالية في Firestore ضمن المسار `users/{uid}/students/{studentId}`؛ لا تغيّر هذا المسار كي لا تفقد الوصول إلى البيانات الحالية.

## ملفات المشروع
- `index.html`: واجهة التطبيق.
- `FIRESTORE_RULES.txt`: نموذج قواعد Firestore المقيدة بحساب المستخدم.
- `functions/index.js`: وظائف خلفية لإرسال رمز بريد رقمي والتحقق منه.
- `functions/package.json`: اعتماديات الوظائف.
- `OTP_SETUP.md`: خطوات إعداد البريد والهاتف قبل التفعيل.

## المزايا الموجودة في الواجهة
- لوحة تحكم عربية متجاوبة.
- إدارة سجلات الطلاب ومجموعاتهم واشتراكاتهم.
- تسجيل الحضور والغياب بالتاريخ.
- تسجيل المدفوعات وعرض ملخص مالي تقديري.
- متابعة التسميع والحفظ وتقييم الطالب.
- تصدير الطلاب والحضور إلى CSV قابل للفتح في Excel.
- تخزين البيانات في Firestore لكل حساب.

## إعداد Firebase
1. فعّل Email/Password في Firebase Authentication لاستخدام تسجيل الدخول الحالي.
2. تأكد من نشر قواعد `FIRESTORE_RULES.txt` من Firestore > Rules.
3. فعّل Phone provider واضبط SMS region policy والدومين المسموح إذا كنت ستختبر تسجيل الهاتف.
4. راجع `OTP_SETUP.md` لإعداد وظائف البريد والخطوات المطلوبة.

## مهم بشأن التحقق
**التحقق الإلزامي برمز رقمي للبريد والتحقق برمز SMS للهاتف غير مفعّلين بالكامل في واجهة التسجيل الحالية.** ملف وظائف البريد هو هيكل خلفي يحتاج إعداد أسرار SMTP وApp Check ثم نشرًا واختبارًا. لا تعتبر التحقق جاهزًا قبل إكمال الربط واختبار الإرسال والتحقق من الرمز والهاتف فعليًا.

## النشر
من Settings > Pages اختر Deploy from a branch ثم `main` والمجلد `/(root)`.
الرابط المتوقع: https://marwanelnagar.github.io/al-naggar-smart-system/

## الأمان
- لا تضع كلمات مرور SMTP أو مفاتيح خدمة داخل ملفات الواجهة أو GitHub.
- لا تسمح للمتصفح بقراءة أو كتابة مجموعة `emailOtpChallenges`.
- لا تدخل بيانات طلاب حقيقية قبل التأكد من قواعد Firestore المنشورة واختبار صلاحيات الحسابات.
